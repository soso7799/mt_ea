## 執行

保持 FTMO 的 MT5 開啟並登入，然後：

```
G:\我的雲端硬碟\src\mt_ea\scripts\build_report.bat
```

- 16 個商品約 5 分鐘。輸出到 `H:\我的雲端硬碟\reports\跨週期分析_<時間>.xlsx`，並覆蓋 `跨週期分析_最新.xlsx`。
- K 線快取在 `H:\我的雲端硬碟\export\bars_mtf\`，30 分鐘內重跑會直接用快取。
- 指定商品：`build_report.bat --symbols EURUSD XAUUSD US100.cash`
- 儀表板預設商品：`--dashboard XAUUSD`（打開後也可以在 B5 下拉選單切換）

## 怎麼讀

- **只看「後 30%」的數字**。前 70% 是挑參數用的，每個商品比較上千種組合，最佳值一定偏樂觀。
- 「可進場」= 後 30% 交易 ≥20、獲利因子 ≥1.3、t 值 ≥2.5；「觀察」門檻較低；「排除」= 前 70% 最好的規則到後 30% 扣點差後虧損。
- 16 個商品同時檢驗，**即使完全隨機也可能有 1 個碰巧過關**。可進場的規則仍需用 Python 回測 / MT5 測試器以最新資料再確認。

## 指標應用診斷（diagnose.bat）

回答「指標是不是用反了」：

```
G:\我的雲端硬碟\src\mt_ea\scripts\diagnose.bat
```

約 1–2 分鐘（沿用 build_report 的 K 線快取，24 小時內不重抓），輸出 `reports\指標應用診斷_<時間>.xlsx`：

- **總覽（持有5根）**：每個指標的「翻轉」「極端」與 11 指標「共識」訊號，在各週期、各盤勢的判讀
  - 綠 **照訊號做有效**：照訊號方向做有優勢（且大於點差、前後半段一致）
  - 藍 **反著做有效**：訊號後價格回頭，要反過來做 → 目前用反了
  - 黃 **…但不夠付成本**：有方向但小於點差
- **明細**：持有 1/3/5/10/20 根的平均報酬（ATR 單位）、t 值、勝率、成本
- **各商品**：每商品每週期的結果

以模擬資料驗證過：隨機行情 0 項誤判；均值回歸行情會判出「極端＝照訊號做有效、翻轉/共識＝反著做有效」；
趨勢行情則相反。
