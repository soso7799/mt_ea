## 怎麼讀

- **只看「後 30%」的數字**。前 70% 是挑參數用的，每個商品比較上千種組合，最佳值一定偏樂觀。
- 「可進場」= 後 30% 交易 ≥20、獲利因子 ≥1.3、t 值 ≥2.5；「觀察」門檻較低；「排除」= 前 70% 最好的規則到後 30% 扣點差後虧損。
- 16 個商品同時檢驗，**即使完全隨機也可能有 1 個碰巧過關**。可進場的規則仍需用 Python 回測 / MT5 測試器以最新資料再確認。

## 關卡突破 / 反轉研究（levels_study.bat）

先用關卡決定「位置」，指標與成交量只在價格碰到關卡時用來判斷「突破還是反轉」：

```
G:\我的雲端硬碟\src\mt_ea\scripts\levels_study.bat            （M15，約 10 個月）
G:\我的雲端硬碟\src\mt_ea\scripts\levels_study.bat --tf H1    （H1，約 2 年，樣本期間較長）
```

- **關卡**：昨日高/低/收；昨日亞盤、歐盤、美盤的高/低/收；上週高/低/收（每天用前一日資料算好）。
- **觸碰**：價格從一側靠近並碰到關卡；每條關卡每天只記第一次。
- **突破 / 反轉**：以下一根開盤（實際進場價）為基準，往後 3 小時內先往穿越方向走 0.5 ATR = 突破，先往回走 0.5 ATR = 反轉。
- **判斷依據**（只在觸碰當下看）：成交量比、觸碰 K 線是否收在關卡外、RSI/KD/CCI 是否同向極端、ADX 盤勢、EMA50 趨勢、TAI 動能、關卡共振、時段。

Excel 分頁：

| 分頁 | 內容 |
|------|------|
| 今日關卡 | 每商品今天的所有關卡、距現價幾個 ATR、上方壓力/下方支撐、共振數、該關卡歷史突破率 |
| 各關卡突破反轉率 | 每種關卡被碰到後突破 / 反轉的比例（z 值 ≥2 偏突破、≤-2 偏反轉） |
| 觸碰條件分析 | 各條件下突破率如何變化（例如量增時是否更容易突破） |
| 成交量x收盤 | 成交量與觸碰 K 線收盤位置的交叉表 |
| 規則回測 | 所有條件組合 × 突破/反轉 × SL/TP：前 70% 挑選、後 30% 驗證（扣點差與 FTMO 外匯手續費 5 USD/手） |
| 最佳規則各商品 | 前 70% 最佳規則在每個商品的表現 |

**可信** = 前 70% t≥2，且後 30% t≥3、≥50 筆、≥60% 商品獲利。組合上千種，只有「可信」的規則值得寫成 EA。

以 16 商品隨機資料驗證：整體突破/反轉各約 47%，可信規則 0 條（沒有誤報）。
